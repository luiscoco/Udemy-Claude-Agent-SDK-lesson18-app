Prepare Node and Git

Use Node.js 24+, npm, Git, your own Anthropic key and model access. Windows may need Git Bash. The release exercise creates its own owned repository and does not modify global Git identity.

Preserve an existing .env or copy the safe example. Enter your own key locally and keep it out of shared source.

Write and dispatch a project skill

Start the server and open port 3118. Edit the description, run Project /security-check, then inspect the actual generated SKILL.md and returned findings.

04

Compare model invocation and pre-approval

Run Natural request, then Pre-approve in SKILL.md. Confirm actual file reads and no host fallback approval requests. allowedTools pre-approves; it does not restrict by itself.

05

Compare personal discovery and missing sources

Run Personal with user as its source. Then run Missing source: files still exist, but classroom discovery is disabled and a plain review is requested.

06

Create release notes and tune descriptions

Run /release-notes against the exported actual classroom commits. Then select Tune, edit the description and inspect invocation in a fresh session. Keep the result as observed behavior rather than a guaranteed trigger rate.

npm run sample:env -- release
npm run sample:env -- tuned
npm test

Your .env configuration

ANTHROPIC_API_KEY=your_api_key
CLAUDE_MODEL=claude-sonnet-4-6
PORT=3118
# Windows if needed: CLAUDE_CODE_GIT_BASH_PATH=C:/Program Files/Git/bin/bash.exe

The npm scripts load the optional .env explicitly. Existing shell variables take precedence. Restart after edits. No Managed Agents agent or environment ID is needed.

Troubleshooting

If this app is already listening, startup prints its URL. If another service occupies the port, change PORT or stop that service. On Windows set CLAUDE_CODE_GIT_BASH_PATH to the installed bash.exe if necessary. Keep optional npm dependencies enabled. Check key/model access if a real query fails; errors are never replaced by a saved answer.
